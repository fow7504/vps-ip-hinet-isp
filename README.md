## 台湾VPS购买前，你得先搞清楚这几个概念

先泼一盆冷水：台湾VPS不是买来当"国内加速器"用的。丽萨主机官网明确写着，台湾走的是BGP国际网络，属于非大陆直连优化线路，联通和部分地区移动直连的效果还可以，但如果你对延迟比较敏感（比如游戏、实时通讯），大陆用户直连台湾的体验并不理想，官方也直接建议通过香港或日本节点中转使用。这一点在多篇第三方测评里也得到了印证，实测大陆直连台湾的延迟大概在280ms左右，确实容易让敏感场景卡顿。所以买之前先想清楚一个问题：你是要直连使用，还是打算当"落地机"，配合一台低延迟的香港或日本VPS做中转架构。这两种用法对配置的要求完全不同。
